# 2048

## Kurzidee

Zahlenkacheln werden auf einem 4×4-Feld verschoben. Gleiche Werte verschmelzen, wodurch immer höhere
Kacheln entstehen. Die Partie endet, wenn kein gültiger Zug mehr möglich ist.

## App

- Vorgesehene App-ID: `number-merge`
- Arbeitstitel: `2048`
- Datenbesitz: Gerät
- Persistenz: Highscore, höchste Kachel und laufende Partie

## Spielablauf und Steuerung

- Wischen in vier Richtungen verschiebt alle Kacheln.
- Im Entwicklungsmodus funktionieren zusätzlich die Pfeiltasten.
- Nach jedem gültigen Zug erscheint eine neue Kachel mit dem Wert 2 oder selten 4.
- Beim Erreichen von 2048 darf weitergespielt oder eine neue Runde gestartet werden.
- Undo ist im MVP nicht vorgesehen.

## MVP

- Klassisches 4×4-Feld mit klaren Bewegungs- und Verschmelzanimationen.
- Punktzahl steigt um den Wert jeder neu entstandenen Kachel.
- Bestätigung vor dem Überschreiben einer laufenden Partie.
- Darstellung bleibt auch bei größeren Werten lesbar.

## Tests und Abnahme

- Jede Reihe beziehungsweise Spalte wird in einer Richtung korrekt komprimiert und verschmolzen.
- Eine Kachel darf pro Zug nur einmal verschmelzen.
- Bei einem ungültigen Zug wird keine neue Kachel erzeugt.
- Game Over wird nur erkannt, wenn weder freie Felder noch mögliche Verschmelzungen existieren.
