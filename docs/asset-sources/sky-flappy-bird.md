# Sky-Flappy-Vogel

Der Vogel ist eine eigenständig gezeichnete, projektinterne SVG-Grafik. Körper, Vorderflügel und
ferner Flügel sind getrennt, damit die Bewegung per CSS animiert werden kann.

Als Bewegungsreferenz diente die achtphasige, gemeinfreie Animation
[Flying Bird Animation](https://freesvg.org/flying-bird-animation) von FreeSVG/OpenClipart. Die
Projektgrafik übernimmt keine fertigen Pfade oder Frames aus dieser Vorlage.
