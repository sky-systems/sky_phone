# Snake progression artwork

Generated with the built-in image_gen tool. Reference: `frontend/src/assets/img/app-previews/snake.jpg`.

Original green snake and apple stay in CSS; new fruit and head sprites use transparent WebP at up to 128 px. Only empty padding was trimmed and resolution reduced for the game.

## strawberry.webp

Create a single transparent-background game sprite: one ripe strawberry with small fresh green leaves. Use the attached existing Snake game preview as the visual style reference: simple rounded friendly shapes, bright warm fruit color, soft minimal dimensional shading and one gentle highlight, clean silhouette that reads at 20 pixels. This is a standalone food pickup for the same game. Center the complete strawberry in a square canvas occupying about 85 percent of its height. No text, no UI, no frame, no ground, no scene, no cast shadow beyond the silhouette. Actual transparent alpha background. Do not include a snake or apple. Export a square PNG.
